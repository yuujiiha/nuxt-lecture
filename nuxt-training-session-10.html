Unit Test

utilsは
入出力を素早く確認

Arrange / Act / Assert

準備・実行・検証を分けると、テストの意図が読みやすい。

境界値も含める

通常値だけでなく、0、空文字、上限、無効値を確認する。

// test/unit/formatPrice.test.ts
import { describe, expect, it } from 'vitest'
import { formatPrice } from
  '~/utils/formatPrice'

describe('formatPrice', () => {
  it('3桁ごとに区切り円を付ける', () => {
    // Arrange
    const price = 1200

    // Act
    const result = formatPrice(price)

    // Assert
    expect(result).toBe('1,200円')
  })
})

Nuxt runtimeとE2Eは同じtest fileへ混ぜず、環境を分ける。

// test/nuxt/UserCard.nuxt.spec.ts
import { mountSuspended } from
  '@nuxt/test-utils/runtime'
import { UserCard } from '#components'

it('編集操作を親へ通知する', async () => {
  const wrapper = await mountSuspended(
    UserCard,
    { props: { user } },
  )

  await wrapper.get('button').trigger('click')

  expect(wrapper.emitted('edit'))
    .toEqual([[user.id]])
})
