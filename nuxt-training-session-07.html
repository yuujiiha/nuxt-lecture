Validate Every Input

入力は「型」だけでなく
「値」も検証する

検証対象

  • path params
  • query parameters
  • request body
  • headers・cookies
  • 認証済みユーザーの権限

TypeScriptの型は実行時の外部入力を守らない。

export default defineEventHandler(async (event) => {
  const body = await readValidatedBody(
    event,
    createUserSchema.parse,
  )

  const session = await requireSession(event)
  if (!session.canCreateUser) {
    throw createError({
      status: 403,
      statusText: 'Forbidden',
    })
  }

  return userRepository.create(body)
})

Takeaways

今日の3つの規約

外部入力はserverで検証し、認証と認可を分けて確認する。

秘密値はprivateなruntimeConfigへ置き、clientへ渡さない。

APIは必要なデータだけ返し、内部エラーと公開messageを分離する。

次のPRでは、APIごとに入力・権限・返却値・ログを確認する。
